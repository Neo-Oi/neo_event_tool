# トレーサビリティ一覧（項目番号からの逆引き）

作成日：2026年7月31日

`結合試験仕様書.md` 5章は **IF → 項目番号** の方向しか持っていない。
本書はその逆で、**項目番号から IF・区分・エビデンスを引く**。
並びは `結合試験項目一覧.xlsx` の行順と同一なので、番号で1行ずつ突き合わせられる。

## 突き合わせ方

| 見たいもの | 引き方 |
|---|---|
| 番号 → 試験の中身 | `結合試験仕様書.md` 3章、または Excel の同じ番号の行 |
| 番号 → エビデンス | 本書の表、または `evidence/` を番号で前方一致（`3-3-1_*`） |
| 番号 → 実施記録 | Excel の同じ番号の行（**履歴欄にエビデンスのファイル名が入っている**） |
| 番号 → IF | 本書の表（IF列） |
| IF → 番号 | `結合試験仕様書.md` 5章 |
| エビデンス → 番号 | ファイル名の先頭が項目番号（`<項目番号>_<YYYYMMDD>_<連番>.png`） |

**エビデンスのファイル名は先頭が項目番号なので、番号そのものが結合キーになる。**
