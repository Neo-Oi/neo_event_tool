# 機能一覧

作成日：2026年7月28日

画面ごとに、その画面でできることを並べたものです。
仕様の詳しい内容は `要件定義書.md` の F 番号を見てください。

**見方**

- 「要件」は `要件定義書.md` の番号です
- ★ が付いている機能は、データを保存します（それ以外は表示のみ）

---

## 主催者側

### S-1 ダッシュボード

運営の全体状況を1画面で見ます。

| 機能 | 内容 | 要件 |
|---|---|---|
| 指標カード | 進行中のイベント数／今週の申込数／要対応件数／下書き件数 | F-30 |
| 申込ヒートマップ | 全イベントをまとめて、直近26週の日別申込数を色の濃さで表示 | F-103 |
| 要対応リスト | 手を打つ必要があるイベントと、次に何をするかを表示 | F-31, F-31b |
| 開催カレンダー | 月表示。イベントを開催日のマスに帯で表示。前月・次月へ移動できる | F-100 |

### S-2 イベント一覧

イベントをカードで一覧します。

| 機能 | 内容 | 要件 |
|---|---|---|
| 時期で絞り込み | 未定／これから／終了・中止 の3つを個別にオンオフ | F-44 |
| イベントカード | 状態・開催日時・会場に加えて、申込バーと準備の進捗バーを表示 | F-79 |
| 要対応の見出し | 未読・期限超過・未対応タスク・未解決Q&A の件数をカードに表示 | F-79b |
| 新規作成 | S-3 へ移動 | F-01 |

### S-3 イベント作成・編集

5つのステップに分けて入力します。

| 機能 | 内容 | 要件 |
|---|---|---|
| ステップ1 基本情報 | イベント名・開始日時・終了日時 | F-69 |
| ステップ2 会場 | 開催形式（現地／オンライン／ハイブリッド）・会場名・住所・視聴URL | F-69, F-93 |
| ステップ3 詳細 | 説明・対象者・カバー画像 | F-03, F-69 |
| ステップ4 申込 | 定員・受付開始日・申込締切・**追加の質問** | F-45b, F-69, F-91 |
| ステップ5 設定 | 公開範囲・問い合わせ先 | F-64, F-69 |
| ★ 保存して次へ | 押すたびに下書きとして保存する。途中でやめても残る | F-70, F-72 |
| 公開前チェック | 必須項目の抜けや日付の矛盾を一覧で表示 | F-06 |
| ★ 公開する | 確認してから公開。不備があると公開できない | F-06, F-87 |

### S-4 イベント詳細

上部にイベントの状況を固定表示し、下を9つのタブで切り替えます。

**固定表示** … イベント名・状態・時期・開催日時・会場・申込数と定員・残席・タスク進捗（F-76）

#### タブ1 申込

| 機能 | 内容 | 要件 |
|---|---|---|
| 申込一覧 | 氏名・カナ・状態・操作の4列 | F-22, F-77 |
| 絞り込み | 氏名・カナ・メールで検索。全角半角やひらがなカタカナの違いを吸収する | F-23, F-47 |
| 申込推移 | 日別の申込数をグラフで表示 | F-96 |
| ★ チェックイン／取消 | 行のボタンを1回押すだけ | F-24 |
| ★ QRで受付 | カメラで参加者のQRを読み取って受付する（1台のみ） | F-95 |
| 行を開く | メールアドレス・申込日時・受付時刻・質問への回答を表示 | F-78 |
| ★ 内容を修正 | 氏名・カナ・メールを直す | F-26 |
| ★ 申込をキャンセル | 記録は残したまま状態だけ変える | F-25 |
| CSV出力 | 追加の質問への回答も列として出す | F-28, F-49b |

#### タブ2 運営スレッド

| 機能 | 内容 | 要件 |
|---|---|---|
| ★ 投稿・削除 | 運営メンバー間のチャット | E-1 |
| 未読の表示 | 前回開いた時刻より後の投稿を未読として数える | F-79c |

#### タブ3 運営Q&A

| 機能 | 内容 | 要件 |
|---|---|---|

| ★ 回答を保存 | 回答や対応内容を書く | E-1 |
| ★ 解決にする／戻す | 未解決のものが上に並ぶ | E-1 |

#### タブ4 運営タスク

| 機能 | 内容 | 要件 |

| ★ ドラッグで移動 | 列をまたぐと状態が変わり、そのまま保存される | E-2 |

#### タブ6 ファイル

|---|---|---|

| ★ 取り下げる | 参加者からも見えなくなる | E-4 |

#### タブ8 告知

#### タブ9 概要・編集

| 機能 | 内容 | 要件 |
|---|---|---|

| 参加者ビューで確認 | 下書きのままでも参加者からの見え方を確認できる | F-07 |

| ★ 中止する | 確認モーダルあり。既存の申込は変えない | F-39 |
| ★ 削除 | 下書きのときだけ | F-01 |

### S-5 設定

| 機能 | 内容 | 要件 |

| 一覧 | 氏名・カナ・メール・参加回数・来場回数・最終申込日 | F-92 |
| 絞り込み | 氏名・カナ・メールで検索 | F-92 |
| 参加履歴 | 行を開くと、その人が申込んだイベントの一覧が出る | F-92 |
| CSV出力 | 名簿をまとめて出す | F-92 |

## 参加者側

### イベントを探す（公開ページの一覧）

| 機能 | 内容 | 要件 |
|---|---|---|
| 一覧 | 一般公開かつ**今から申込める／これから受付が始まる**イベントのみ。イベント名・開催日時・会場・残席を出す | F-83b |

## 画面をまたぐ機能

| 機能 | 内容 | 要件 |
|---|---|---|
| 役割の切替 | ヘッダーで主催者ビューと参加者ビューを行き来する。**主催者ビューへ戻ると参加者はログアウトする** | F-29, F-107 |
| タブ | 主催者は4つ（ダッシュボード／イベント／参加者／設定）、参加者は2つ | F-29 |
| URLからの復帰 | `?event=` で公開ページ、`?ticket=` で申込詳細、`?preview=` で下書き確認 | F-97 |
| 画面幅 | **参加者ビューはスマホ幅に対応する。主催者ビューはPC幅のみ** | F-81, F-81b |
| 時期の自動判定 | 受付前・受付中・受付終了・開催済を、日付と現在時刻から毎回計算する | F-05 |
| エラー表示 | 入力エラーは項目の下、完了はトースト、システムエラーは上部バナー、取り消せない操作は確認モーダル | F-84〜F-87 |
| データがないとき | 各画面で案内を出す | F-35 |

## 作らないと決めた機能

理由つきの一覧は `Peatix比較.md` にあります。主なものだけ挙げます。

| 機能 | 作らない理由 | 要件 |
|---|---|---|
| 代理申込 | メールアドレスで人を見分けているため、1つのアドレスに複数人をぶら下げると名簿が壊れる | F-104 |
| 申込の譲渡 | 譲渡先の本人確認ができない | F-105 |
| 抽選 | 当落を知らせる手段がない | F-106 |
| キャンセル待ち | 繰り上がったことを知らせる手段がない | — |
| メール送信 | サーバがないため | — |
| チケット制 | 無料イベントで「チケットを買う」操作は不要と判断した | — |
