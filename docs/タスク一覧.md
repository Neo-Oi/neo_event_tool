## Backlog登録時の注意

| 項目 | 内容 |
|---|---|
| テンプレート | 「課題」画面 →「一括登録」→「サンプルをダウンロード」で取得。2行目以降に入力し、1行目は削除しない |
| 必須項目 | 件名、種別名 |
| 状態 | 入力できない。すべて「未対応」で登録される |
| 種別名 | 添付CSVは「タスク」で統一。プロジェクト側の種別名と一致させる |
| 列名の不一致 | アップロード後の「マッピングの設定」で対応付ける |
