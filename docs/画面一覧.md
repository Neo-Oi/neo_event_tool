## 1. 画面の一覧

「経路」は `App` のルータのページ名。**単一HTMLのため通常は URL が変わらない**（復帰用のパラメータを除く / F-97）。

| # | 画面名 | ビュー | 経路 | 到達方法 | 主な構成要素 |
|---|---|---|---|---|---|
| S-1 | ダッシュボード | 主催者 | `dashboard` | タブ「ダッシュボード」（起動時の初期画面） | 指標カード4枚／申込ヒートマップ（直近26週）／要対応リスト／開催カレンダー（月表示） |
| S-2 | イベント一覧 | 主催者 | `events` | タブ「イベント」 | 時期トグル3つ（日程未定／これから／終了・中止）／イベントカード（状態と時期のバッジ・申込バー・準備の進捗バー・要対応の見出し）／新規作成 |
| S-3 | イベント作成・編集 | 主催者 | `create` | S-2 の「＋ 新規作成」、S-4 の「✎ 編集する」 | 5ステップ（1.基本情報／2.会場／3.詳細／4.申込／5.設定）／公開前チェック／下書き保存／公開 |
| S-4 | イベント詳細 | 主催者 | `eventDetail` | S-1 の要対応・カレンダー、S-2 のカード、S-10 の参加履歴、S-11 の通知 | 上部の固定表示（状態・時期・日時・会場・申込／定員・残席・タスク進捗）＋サブタブ9つ（2章） |
| S-5 | 設定 | 主催者 | `settings` | タブ「設定」 | デモデータを投入／データベースを初期化 |
| S-6 | 公開ページ | 参加者 | `public` | S-6a の一覧、S-9 の「公開ページを開く」、S-4 の「参加者ビューで確認」、`?event=` / `?preview=` | カバー画像／開催日時・開催形式・会場（地図リンク）・対象者・受付期間／お知らせ／説明／残席／申込ボタン／問い合わせ先 |
| S-6a | イベントを探す（一覧） | 参加者 | `list` | タブ「イベントを探す」（参加者ビューの初期画面） | 受付中・受付前のイベントのカード（カバー画像の帯・日時・会場・残席）。満席も出す |
| S-7 | 申込フォーム | 参加者 | `apply` | S-6 の「申込む」 | 入力（氏名・カナ・メール＋追加質問＋案内受取の同意）と確認の2段階を画面内で切り替える |
| S-8 | 申込完了 | 参加者 | `complete` | S-7 の「申込む」 | 完了メッセージ／申込内容の要約／マイ申込への導線／折りたたんだ確認URL |
| S-9 | マイ申込 | 参加者 | `myticket` | タブ「マイ申込」、S-8 の導線、`?ticket=` | ログイン → 一覧（カバー画像の帯・日時・状態）→ 詳細（視聴URL・受付用QR・お知らせ・キャンセル）を画面内で切り替える |
| S-10 | 参加者名簿 | 主催者 | `roster` | タブ「参加者」 | パスワードによるロック解除／横断一覧（参加回数・来場回数・最終申込日）／参加履歴の展開／正規化検索／CSV出力 |
| S-11 | 通知 | 両方 | `notify` | タブ「通知」 | 変更・追加を新しい順に一覧（日時・種類・イベント名・内容）／未読の印／クリックで該当箇所へ移動 |

**S-6a は S-6 と同じ公開ページ系の画面**で、要件定義書では S-6 に含めて扱う。経路と到達方法が別なので、本書では行を分けた。

## 2. S-4 のサブタブ

| # | サブタブ | 内容 | 参加者から見えるか |
|---|---|---|---|
| 1 | 申込 | 一覧・検索・チェックイン・QR受付・内容修正・キャンセル・CSV出力・申込推移 | — |
| 2 | 運営スレッド | 運営メンバー間のチャット | 見えない |
| 3 | 運営Q&A | 疑問の登録と解消 | 見えない |
| 4 | 運営タスク | ボード（カンバン）とタイムライン | 見えない |
| 5 | マニュアル | 当日の手順書（編集／分割／プレビュー） | 見えない |
| 6 | ファイル | 会場図・資料の共有 | 見えない |
| 7 | お知らせ | 参加者への連絡 | **内容が S-6 と S-9 に掲示される** |
| 8 | 告知 | 共有URL・投稿文・SNS共有 | — |
| 9 | 概要・編集 | 内容の確認／複製／公開・中止・削除 | — |

初期表示は「申込」。**S-11 の通知から開いた場合は、その通知に対応するサブタブが選ばれる。**

## 3. ビューとタブ

役割の切替はヘッダーで行う。**ビューを切り替えると S-10 は再ロックされ、参加者のログインは解除される。**

| ビュー | タブ（かっこ内は属する画面） | 画面幅 |
|---|---|---|
| 主催者 | ダッシュボード（S-1）／イベント（S-2・S-3・S-4）／通知（S-11）／参加者（S-10）／設定（S-5） | PC幅のみ |
| 参加者 | イベントを探す（S-6a・S-6・S-7・S-8）／マイ申込（S-9）／通知（S-11） | スマホ幅に対応 |

## 4. 画面遷移

```
■ 主催者
  S-1 ダッシュボード ⇄ S-2 イベント一覧 ──→ S-3 作成・編集
        │                   │                     │
        └───────┬───────────┘                     │（保存・公開）
                ↓                                 ↓
           S-4 イベント詳細 ←────────────────────┘
                │  ├─ 複製 ──→ S-4（新しい下書き）
                │  └─ 参加者ビューで確認 ──→ S-6（プレビュー）
  S-10 参加者名簿 ── 参加履歴のイベント名 ──→ S-4
  S-11 通知 ── 該当サブタブを指定 ──→ S-4
  S-5 設定（タブから直接）

■ 参加者
  S-6a 探す ──→ S-6 公開ページ ──→ S-7 申込フォーム（入力→確認）──→ S-8 完了 ──→ S-9 マイ申込
                     ↑                                                                   │
                     └────────────── 公開ページを開く ─────────────────────────────────┘
  S-11 通知 ── イベント名 ──→ S-6

■ URL からの復帰（F-97。処理後に URL は元に戻る）
  ?ticket=<token> ──→ S-9 の詳細（ログイン不要）
  ?event=<id>     ──→ S-6（限定公開はこの経路のみ）
  ?preview=<id>   ──→ S-6（下書きのプレビュー）
```

## 5. 画面に入る前の条件

| 画面 | 条件 |
|---|---|
| S-10 参加者名簿 | パスワードが必要。解除はセッション内のみで、再読込・参加者ビューへの切替で再びロックする |
| S-9 マイ申込（一覧） | ログインが必要。**確認URL（`?ticket=`）で開く個別の1件は不要** |
| S-11 通知（参加者側） | ログインが必要（自分が申込んだイベントの分だけを出すため） |
| S-6 公開ページ | 下書きは表示しない（`?preview=` で開いたときだけ表示する） |
| S-7 申込フォーム | 公開中・受付中・残席ありのときだけ入れる。満席・受付前・受付終了・中止は理由を表示して止まる |

## 6. 画面共通の要素

| 要素 | 内容 |
|---|---|
| ヘッダー | 会社ロゴ（クリックで会社サイト）／アプリ名／役割の切替／利用者の表示 |
| タブ | ビューごとに切り替わる（3章）。**通知タブには未読件数のバッジ**が出る |
| 入力エラー | 該当項目の直下に表示し、最初のエラー項目へフォーカスする |
| 完了 | 画面右下にトーストを出し、数秒で消す |
| システムエラー | 画面上部のバナーに出し、閉じるまで残す |
| 取り消せない操作 | 公開・中止・削除・初期化・申込のキャンセル・お知らせの取り下げは確認モーダルを出す |
| 空の状態 | データが無い画面では、次に何をすればよいかを添えて案内する |
